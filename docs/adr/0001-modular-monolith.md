# ADR-0001: Модульный монолит с жёсткими границами

- Статус: принято

## Контекст
Одна команда, быстрый старт, но нужен путь к масштабированию и разным компаниям.
Код во многом пишет AI-агент, который склонен срезать углы между модулями.

## Решение
Один FastAPI-процесс + arq-воркер. Модули с слоями domain/application/infrastructure/api
и единственной точкой входа `public.py`. Границы проверяет import-linter в `make check`.

## Альтернативы
Микросервисы с первого дня — избыточная инфраструктура и сетевые сбои без выгоды на старте.
Монолит без границ — быстро деградирует.

## Последствия
Любой модуль можно вынести в сервис, заменив реализацию `public.py` клиентом.
Нарушение границ ломает сборку — это намеренно.
