# ADR-0005: JSON Schema как источник истины для контрактов

- Статус: принято

## Решение
Схемы в `packages/contracts/schemas/`, генерация Pydantic и TS через `make contracts`.
`make check` падает, если сгенерированный код неактуален. Ручное редактирование generated запрещено
(хук блокирует).

## Последствия
Бэкенд и фронтенд не расходятся; изменения протокола видны в одном месте.
