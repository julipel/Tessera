# ADR-0003: Каталог — структурированный поиск, векторы — для текстов

- Статус: принято

## Контекст
Запросы вида «синие, до 5000, в наличии» векторный поиск решает плохо и недостоверно.

## Решение
Структурированные данные нормализуются в Entity (Postgres, нормализованные поля + JSONB).
`search_catalog` фильтрует структурно, семантика — дополнительно по описанию.
Документы и тексты — гибридный поиск в Qdrant.

## Последствия
Для каждого табличного источника нужен маппинг полей в конфиге.
