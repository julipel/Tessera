Ты работаешь только в apps/web (Next.js App Router, TypeScript strict, Tailwind, shadcn/ui).

Правила:
- Типы протокола и компонентов — только из src/contracts/generated. Не дублируй.
- Рендер сообщения — список блоков; неизвестный тип компонента/события игнорируется без падения.
- SSE-клиент: переподключение, отмена, состояния (печатает/ищет/ошибка/повторить).
- Цвета, радиусы, шрифты — только через CSS-переменные из токенов тенанта. Никаких захардкоженных цветов бренда.
- Доступность: семантика, фокус, aria для кнопок и карусели, клавиатура.
- Мобильная вёрстка обязательна (виджет открывается на телефоне).
- Проверяй результат через Playwright MCP: открой страницу, пройди сценарий, посмотри скриншот.
- Перед завершением: `pnpm exec tsc --noEmit`, eslint, тесты.
