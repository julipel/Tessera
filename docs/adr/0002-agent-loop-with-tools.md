# ADR-0002: Агент как цикл с вызовом инструментов

- Статус: принято

## Контекст
Нужен многошаговый диалог с уточнениями, а не «вопрос → поиск → ответ».

## Решение
Агентный цикл: модель на каждом шаге решает — ответить, уточнить или вызвать инструменты.
Поиск по знаниям, каталогу, API компании и показ UI — инструменты. Лимиты шагов/времени/токенов.
LLM за портом `LLMClient`, провайдеры взаимозаменяемы.

## Альтернативы
Фиксированный RAG-пайплайн — не умеет уточнять и комбинировать источники.
Готовые агентные фреймворки (LangGraph и т. п.) — лишний слой абстракций над простым циклом,
сложнее отлаживать стриминг и контролировать события.

## Последствия
Качество зависит от промптов и описаний инструментов → нужен набор эвалов (P3).
Цикл покрывается тестами на FakeLLM до реализации.
