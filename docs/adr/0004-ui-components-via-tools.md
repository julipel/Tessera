# ADR-0004: UI-компоненты создаются инструментами бэкенда

- Статус: принято

## Контекст
Карточки товаров с ценами и ссылками, сгенерированные моделью, могут содержать выдуманные данные.

## Решение
Модель вызывает инструмент (`show_entities(ids, layout)`), бэкенд собирает компонент из БД
и отправляет событие `component`. Компоненты типизированы схемами из packages/contracts.

## Последствия
Модель оперирует id, а не данными. Новый тип компонента = схема + генерация + React-компонент.
