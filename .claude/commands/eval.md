---
description: Прогнать эвалы и разобрать результаты
argument-hint: [фильтр диалогов]
---
Запусти `make eval` (фильтр: $ARGUMENTS, если задан). Затем:

1. Сравни с предыдущим отчётом (`make eval-diff`), если он есть.
2. Сгруппируй провалы по причинам: не уточнил / лишнее уточнение / не тот инструмент /
   выдуманный факт / потеря контекста / формат / ошибка инструмента.
3. Для каждой группы — гипотеза причины (промпт, описание инструмента, данные, код) и
   конкретное минимальное изменение.
4. Ничего не меняй — жди выбора, какие изменения пробовать.
